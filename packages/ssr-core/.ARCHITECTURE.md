# SSR Framework - Architecture

For LLMs working on the framework source code itself.

For usage documentation, see `llms.txt`.

## Philosophy

- **Minimal**: ~700 lines total, zero runtime dependencies beyond SolidJS + seroval
- **Bun-native**: Uses Bun's runtime, bundler, and plugin system
- **Convention over Configuration**: `*.island.tsx` and `*.client.tsx` naming

## Code Structure

```
src/
├── index.ts       # createConfig(), html(), plugin() - main entry
├── transform.ts   # Babel plugin for island wrapping
├── build.ts       # Island bundling with code splitting
└── adapter/
    ├── bun.ts     # Bun.serve() routes
    ├── hono.ts    # Hono routes
    ├── elysia.ts  # Elysia routes
    ├── client.js  # Dev mode client (reload + dev tools)
    └── utils.ts   # Shared adapter utilities
```

## Key Design Decisions

### render() instead of hydrate()

We use Solid's `render()` instead of `hydrate()`:
- `hydrate()` requires exact DOM matching with `data-hk` keys
- Solid-Start has 1000+ lines just for hydration handling
- `render()` is simple and robust - standard in islands frameworks (Astro, Fresh)

Trade-off: Minimal flicker when replacing SSR content, but much simpler code.

### Props Serialization with seroval

Using seroval instead of JSON for props:
- Supports `Date`, `Map`, `Set`, `RegExp`, `BigInt`, `undefined`
- Supports circular references
- Type-safe

## Bun-Specific Gotchas

### Plugin vs Build API

```typescript
// Bun.plugin() - Runtime (dev mode)
// NO build.onStart() available!
build.onLoad(...)

// Bun.build() - Ahead-of-time bundling  
// build.onStart() IS available
```

Solution: Use `build.onStart?.()` with optional chaining.

### Watch Mode File Registration

`Bun.file(path).text()` doesn't register files with the watcher.

Solution: Import with `?` suffix:
```typescript
const contents = await import(`${path}?`, { with: { type: "text" } });
```

## Debugging

1. **Island not interactive**: Check if file ends with `.island.tsx`, check Network tab for `/_ssr/{hash}.js`
2. **Watch mode not reacting**: Ensure using the `import()` with `?` hack
3. **Check HTML**: Look for `<solid-island data-id="...">` elements
